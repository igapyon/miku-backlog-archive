# 本文中の内部リンク

生成器は、取得済みリソースだと確認できる参照だけをアーカイブ内の相対 HTML リンクへ変換します。URL の見た目だけが似ている外部サイトや、収集していないページをローカル URL として扱いません。通常の安全な URL は、ローカル変換の可否にかかわらず外部リンクとしては保持します。

## 変換する参照

- 取得済み課題のキー（例: `DEMO-1`）
- 同じ課題ページに存在するコメントの `#comment-<ID>`
- 取得元と同じドメインの `https://<domain>/view/<課題キー>`。クエリなしの場合に限る。フラグメントは、取得済みコメントを指す `#comment-<ID>` だけを引き継ぐ。
- 取得元と同じドメインの `https://<domain>/wiki/<プロジェクトキー>/...?...pageId=<Wiki ID>`。`pageId` が唯一のクエリで、対象 Wiki を収集済みの場合に限る。
- 取得元と同じドメイン・プロジェクトの共有ファイル URL `/downloadSharedFile/<プロジェクトキー>/<ファイルID>/<ファイル名>`。クエリ・フラグメントがなく、その ID の共有ファイル本体がアーカイブに保存されている場合に限る。絶対 URL とルート相対 URL、および通常の Markdown リンクを対応するローカル資産への相対リンクに変換する。

変換後は、現在の HTML ファイルからの相対パスを使います。HTML ページへのリンクには `.html` 拡張子を明示します。URL に認証情報が含まれていた場合は、変換前にユーザー情報部を取り除きます。

`http:`、`https:`、`mailto:` を使う通常の Markdown リンク（`[表示名](URL)`）も安全な通常リンクとして表示します。その URL が上記の条件を満たす場合だけ、リンク先をローカル HTML に置き換えます。

## 変換しない参照

- 別ドメイン・別プロジェクト・未収集の課題や Wiki
- アーカイブに含まれない共有ファイル、または本体を保存できなかった共有ファイル
- Box、Google Drive、Dropbox、OneDrive など Backlog 外のストレージサービスへのリンク
- 認識対象以外のクエリ、フラグメント、URL パス
- Wiki の題名や URL スラッグだけによる参照。題名の重複や URL スラッグの対応を推測しないため。

変換しない `http:`、`https:`、`mailto:` URL は、利用者がクリックしたときだけ開く通常の外部リンクとして残します。`javascript:`、`data:` などのスキームはリンク化しません。外部画像 URL は `<img>` を生成せず、通常リンクとしてだけ残します。

Backlog の課題・コメント本文に共有ファイルへのリンクを挿入できます（[課題から共有ファイルへリンクする](https://support-ja.backlog.com/hc/ja/articles/360036147053-%E8%AA%B2%E9%A1%8C%E3%81%8B%E3%82%89%E5%85%B1%E6%9C%89%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%81%B8%E3%83%AA%E3%83%B3%E3%82%AF%E3%81%99%E3%82%8B)）。共有ファイルの個別ダウンロードパス `/downloadSharedFile/<projectKey>/<fileId>/<fileName>` は Backlog ヘルプの案内に基づきます（[共有ファイルや添付ファイルの参照履歴](https://support-ja.backlog.com/hc/ja/articles/360036150113-%E5%85%B1%E6%9C%89%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%82%84%E6%B7%BB%E4%BB%98%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%81%AE%E5%8F%82%E7%85%A7%E5%B1%A5%E6%AD%B4%E3%82%84-%E3%83%80%E3%82%A6%E3%83%B3%E3%83%AD%E3%83%BC%E3%83%89%E3%81%AE%E5%B1%A5%E6%AD%B4%E3%82%92%E6%8A%8A%E6%8F%A1%E3%81%99%E3%82%8B)）。ID は取得済みプロジェクトの共有ファイル一覧と保存済み本体の両方で確認します。ファイル名だけから ID やローカル保存先を推測しません。Backlog の API ダウンロード操作は別のエンドポイントです（[共有ファイルのダウンロード API](https://developer.nulab.com/ja/docs/backlog/api/2/get-file/)）。
