# 本文中の内部リンク

生成器は、取得済みリソースだと確認できる参照だけをアーカイブ内の相対 HTML リンクへ変換します。URL の見た目だけが似ている外部サイトや、収集していないページをローカル URL として扱いません。通常の安全な URL は、ローカル変換の可否にかかわらず外部リンクとしては保持します。

## 変換する参照

- 取得済み課題のキー（例: `DEMO-1`）
- 同じ課題ページに存在するコメントの `#comment-<ID>`
- 取得元と同じドメインの `https://<domain>/view/<課題キー>`。クエリなしの場合に限る。フラグメントは、取得済みコメントを指す `#comment-<ID>` だけを引き継ぐ。
- 取得元と同じドメインの `https://<domain>/wiki/<プロジェクトキー>/...?...pageId=<Wiki ID>`。`pageId` が唯一のクエリで、対象 Wiki を収集済みの場合に限る。

変換後は、現在の HTML ファイルからの相対パスと明示的な `.html` 拡張子を使います。URL に認証情報が含まれていた場合は、変換前にユーザー情報部を取り除きます。

`http:`、`https:`、`mailto:` を使う通常の Markdown リンク（`[表示名](URL)`）も安全な通常リンクとして表示します。その URL が上記の条件を満たす場合だけ、リンク先をローカル HTML に置き換えます。

## 変換しない参照

- 別ドメイン・別プロジェクト・未収集の課題や Wiki
- 認識対象以外のクエリ、フラグメント、URL パス
- Wiki の題名や URL スラッグだけによる参照。題名の重複や URL スラッグの対応を推測しないため。
- 共有ファイルを本文から参照する記法

変換しない `http:`、`https:`、`mailto:` URL は、利用者がクリックしたときだけ開く通常の外部リンクとして残します。`javascript:`、`data:` などのスキームはリンク化しません。外部画像 URL は `<img>` を生成せず、通常リンクとしてだけ残します。
