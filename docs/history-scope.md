# 更新履歴の対応範囲

初期版のアーカイブは、取得時点の現行状態を保存するスナップショットです。過去の状態を完全に再現する履歴アーカイブにはしません。

## 課題

課題本体は取得時点の状態を保存します。コメントはすべて保存し、コメントに付随する `changeLog` は表示対象に含めます。これにより、コメントとして記録されている変更の経緯は確認できます。

一方で、各属性の変更前後を完全な時系列として復元したり、コメントに現れない変更を網羅したりすることは初期版の対象外です。課題の作成・更新日時と作成者・更新者は、取得時点の属性として保存します。

## Wiki

Wiki は取得時点の現行ページ本文、作成・更新情報、添付ファイルを保存します。過去版の本文や添付ファイルを取得・表示しません。

Backlog API には [Wikiページ更新履歴一覧の取得](https://developer.nulab.com/ja/docs/backlog/api/2/get-wiki-page-history/) があり、各版の本文、版番号、作成者、作成日時を取得できます。しかし、履歴を含めると取得量が増え、各版の画像・添付参照の対応も別途必要になります。初期版ではこの API を呼び出しません。

Wiki が無効なプロジェクト、または Wiki を利用できないスペースでは、Wiki ページがないことと取得失敗を区別して記録します。Wiki API の提供条件に変更があった場合も、アーカイブ全体の完了可否を判断できるように記録へ残します。

## 将来の拡張

履歴を必要とする場合は、明示的なオプションとして追加します。少なくとも次を設計してから導入します。

- 版ごとの本文・作成者・作成日時・版番号の保存形式
- 更新履歴 API のページングと中断再開
- 過去版の画像・添付参照をどの版に対応づけるか
- 現行版と過去版を区別する HTML とローカルリンク
- 履歴取得の失敗をアーカイブ全体の成否へどう反映するか
