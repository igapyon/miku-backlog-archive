# ローカルでの閲覧

`render` したページは通常のHTMLと相対パスを使います。アーカイブ全体のフォルダ構成を保ってください。

```text
my-archive/
├── assets/                 # 添付・共有ファイル本体
├── data/                   # 取得済みデータ
├── state/                  # 取得進捗
└── site/
    ├── index.html          # 閲覧の入口
    ├── assets/style.css    # HTML用CSS
    ├── issues/
    ├── wikis/
    └── files/
```

`site/assets/style.css` は表示用CSSです。画像・添付・共有ファイルはアーカイブ直下の `assets/` にあります。HTMLだけ、または `site/` だけをコピーすると、保存済みファイルを含む閲覧一式にはなりません。

## `file://` で開く

アーカイブ全体を読み書きできる場所に展開し、ファイル管理アプリから `site/index.html` を開きます。ネットワーク接続は不要です。CSS、ページ移動、本文画像、添付、共有ファイルを確認してください。

ブラウザーがCSSまたはページの読込を拒否する場合、ファイルが存在していてもそのブラウザー／OSで表示できるとは限りません。ブラウザーとOSの設定を一括で緩めたり、フォルダ権限をまとめて変更したりせず、まずHTTPの手順を試してください。原因の切り分けと、確認した環境・結果は [閲覧確認記録](viewing-verification.md) に残します。

## ローカルHTTPで開く

Python 3.7以降が利用できる場合は、アーカイブ全体を配信ルートにしてサーバーをループバックアドレスだけへbindします。アーカイブの親ディレクトリで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory ./my-archive
```

ブラウザーで `http://127.0.0.1:8000/site/index.html` を開きます。8000番ポートが使用中なら、起動コマンドのポートとブラウザーURLのポートを同じ値に変更します。閲覧後はサーバーを起動した端末で `Ctrl+C` を押して停止します。

公開ルートを `./my-archive/site` にすると、課題・Wiki・共有ファイルから `../../assets/...` で参照するファイルがルート外になります。この場合、ファイル本体がアーカイブに存在していてもHTTP 404になります。renderが作るリンクを手作業で置換したり、シンボリックリンクを追加したりせず、上記のルートと入口を使ってください。

この手順は同じ端末で閲覧するためのものです。アーカイブ全体を配信すると、データJSON、進捗ファイル、manifest、保存ファイルも配信範囲に入ります。生成HTMLはBacklogのアクセス制御を引き継ぎません。社内・インターネット公開の方法として流用せず、公開用には公開するファイルとアクセス制御を設計してください。

## 閲覧に問題があるとき

| 症状 | 確認内容 |
| --- | --- |
| CSSが適用されない | ページ入口、`site/assets/style.css` の実在、ブラウザーが要求したCSS URLと拒否理由を確認する。HTTP閲覧なら公開ルートも確認する。 |
| `ERR_ACCESS_DENIED` でページ移動できない | 拒否されたURL、現在のURL、OS・ブラウザー版、ファイルの保存場所と開き方を記録する。HTTP手順でも同じページを確認する。 |
| 画像・添付・共有ファイルが404 | 課題・WikiページURLとHTTP配信ルート、生成HTMLの相対リンク先、`<archive>/assets/` の実ファイルを照合する。HTTPルートは `<archive>/`。 |
| CLIが収集未完了を報告する | CLIが示す現在の失敗を読み、`node src/cli.mjs report --archive <archive>` で状態を確認する。設定を直した後、同じarchiveとRuntimeを指定してcollectを再実行する。HTTP状態なしのエラーは原因未特定のまま扱う。 |

本ツールの自動参照検査、HTTP回帰確認、実ブラウザーでの確認は別の検査です。それぞれの実施条件と結果は [閲覧確認記録](viewing-verification.md) に記載します。
